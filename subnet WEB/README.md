# ماستەری سەبنێتینگ | Smart Kurds Plus Edition 🌐
### یاری و پلاتفۆرمی هۆشمەندی فێربوونی دابەشکردنی تۆڕ (Subnetting) بە دیزاینی پڕۆفێشناڵی Smart Kurds Plus و زمانی کوردیی ناوەندی (سۆرانی)

ئەم پڕۆژەیە تایبەت دیزاین کراوە بە ڕووکاری مۆدێرنی **Smart Kurds Plus** بۆ خوێندکاران و مامۆستایانی کۆلێژی زانست، تەکنەلۆژیای زانیاری و ئەندازیاری کۆمپیوتەر لە زانکۆکانی کوردستان، بە مەبەستی فێربوون و تێگەیشتنی قووڵ لە چەمکی **دابەشکردنی تۆڕ (Subnetting & VLSM)** بە شێوەیەکی گەیم کراو (Gamified) و کارلێککار.

---

## تایبەتمەندییە سەرەکییەکان (Features)

### ١. چوار مۆدی یاری جیاواز و کارلێککار (Interactive Games):
1. **پشکنەری تۆڕ و ئایپی (IP Detective & Troubleshooter):**
   - فێرخواز وەک ئەندازیاری تۆڕ کێشەی پەیوەندی و پچڕانی ئامێرەکانی تاقیگە و کەمپ چارەسەر دەکات.
   - پشکنینی پینگ (Live Ping Simulator) و دۆزینەوەی هەڵە باوەکان (وەک پێدانی ناونیشانی برۆدکاست یان نێتوۆرک بە هۆست، ناکۆکی ئایپی دووبارە، جیاوازی سەبنێت ماسک، یان گەیتوەی هەڵە).
   - چاککردنەوەی ڕێکخستنی ئامێرەکان و بەرزکردنەوەی تەندروستی گشتی تۆڕەکە بۆ ١٠٠٪.

2. **پێشبڕکێی خێرایی (Speed Subnetter):**
   - لە ماوەی ٦٠ چرکەدا پرسیاری خێرا دروست دەکرێت دەربارەی: Network ID، Broadcast Address، First/Last Usable IP، Subnet Mask، و Magic Number.
   - بەدەستهێنانی کۆمبۆ (Streak Multipliers)، دەنگی سەربەرزانە و خاڵی XP.

3. **ماتریکسی باینەری (Binary Matrix - Bit Flipper):**
   - ٣٢ بیت (٤ ئۆکتێت) بە شێوەی کارلێککار دادەنرێت.
   - فێرخواز بیتەکانی ماسک (0 و 1) دەگۆڕێت و دەبینێت چۆن سنووری نێوان تۆڕ و هۆست دەگۆڕێت و لۆجیکی Bitwise AND بە کرداری دەبینێت.

4. **تاقیکردنەوەی زانکۆ (University Exam Arena):**
   - پرسیارە باوەکانی تاقیکردنەوەکانی زانکۆ لەسەر سەبنێتینگ بە شیکاری ورد و هەنگاو بە هەنگاوی بیرکارییانە (Magic Number Method, Borrowed Bits).

---

### ٢. ژمێرەری بینراوی سەبنێتینگ (Visual Subnet Calculator):
- نووسینی هەر ئایپی و پێشگرێک (/8 تاوەکو /30).
- دەرخستنی:
  - Network ID
  - Broadcast Address
  - Usable IP Range
  - Subnet Mask & Wildcard Mask
  - ژمارەی سیحری (Magic Number) لە ئۆکتێتی دەستکاریکراو
  - شیکاری باینەری لەگەڵ ڕەنگکردنی بیتەکانی تۆڕ و هۆست بە جیاواز
  - خشتەی تەواوی سەبنێتەکانی ئەو سنوورە

---

### ٣. یاساکانی زانکۆ و ڕێبەری خوێندکار (University Cheat Sheet):
- ڕوونکردنەوەی یاسای $2^h - 2$ بۆ هۆستە کارپێکراوەکان
- یاسای $2^n$ بۆ ژمارەی سەبنێتەکان
- تەکنیکی ژمارەی سیحری ($256 - \text{Mask}$)
- خشتەی خێرای CIDR لە /24 تاوەکو /30

---

### ٤. بڕوانامەی لێهاتوویی زانکۆ (Certificate of Mastery):
- توانای نووسینی ناوی قوتابی و بەروار بە شێوەیەکی فەرمی.
- دوگمەی تایبەتی چاپکردن (Print / Save as PDF) کە ڕێکخستنی `@media print`ی بۆ کراوە بۆ پەڕەی فەرمی.

---

### ٥. دووزمانە (Bilingual) و دەنگی هۆشمەند (Web Audio Synthesizer):
- زمانی فەرمی: **کوردیی ناوەندی (سۆرانی)** بە فۆنتی جوان و شێوازی ڕاست بۆ چەپ (RTL).
- توانای گۆڕین بە یەک کلیک بۆ **English**.
- سیستەمی دەنگی تەواو دروستکراو بە Web Audio API (بەبێ پێویستی بە هیچ فایلی دەنگی دەرەکی).
